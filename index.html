핵심 개요

everything-claude-code GitHub 레포(14만 스타)를 소개하며, Claude Code의 컨텍스트 로트(Context Rot) 문제와 비용 절감 방법, 메모리 학습 시스템을 설명하는 영상.

주요 내용
  • 컨텍스트 로트 원인 4가지: 어텐션 희석, 명령 충돌, 토큰 예산 압박, 관련성 미스매치 — CLAUDE.md가 두꺼우면 그 자체로 성능 저하 원인
  • settings.json 3줄로 비용 80% 절감: ①모델을 Sonnet으로(60% 절감) ②maxThinkingTokens 10000으로(숨은 비용 70% 절감) ③서브에이전트 모델을 Haiku로(80% 절감)
  • /clear(무관한 작업 전환 시 컨텍스트 비움)와 /compact(마일스톤 사이 요약 압축) 구분 사용이 핵심. 구현 도중 compact 절대 금지
  • MCP 서버 10개 이하, 활성 도구 80개 이하 유지 권장 — 초과 시 20만 토큰이 7만까지 줄어듦
  • Continuous Learning v2: 작업 패턴을 Instinct 단위로 저장(신뢰도 0.3~0.9), 3개 이상 모이면 Skill 모듈로 자동 승격. /instinct export/import로 팀 공유 가능

  • 쏘라티노 지표 기준 현재 주도주: 원전(건설 포함) > 반도체 > 통신·우주 > 전력기기·친환경 > 방산·고배당(은행·증권) > 2차전지. 한국과 미국 업종 상위가 거의 일치 — 글로벌 자금 흐름이 같은 방향으로 수렴 중
  • 목표가 하향 군집(실적 악화 예상): 소비재(F&F·네이버·카카오·SM·실리콘투·아모레퍼시픽·롯데관광개발·하나투어·하이브·JYP), 자동차(현대차), 보험. 공통 분모 → 내수 소비 위축 + K-콘텐츠·인바운드 기대 꺾임
  • 목표가 상향 군집(실적 호조 예상): 원전 건설사(두산에너빌리티·한전기술급), 전력기기(현대일렉트릭·대한전선), 반도체 기판(LG이노텍·VMI), SK텔레콤(고배당), 은행·증권(보험 제외), LG에너지솔루션(2H26 기대), APR(화장품 유일한 상향)
  • 애널리스트 TP 변화의 의미: 기업 탐방 후 실적 추정치 조정 → 군집이 생기면 그게 시장 컨센서스. 한두 개 예외는 있지만 군집 방향은 틀리지 않는다. '내가 들고 있는 섹터가 하향 군집이면 지금 잘못된 포지션일 가능성 높다'는 자기 점검 도구로 활용
  • 주목할 이상치: 2차전지 TP 상향 종목이 예상보다 많음(포스코퓨처엠 등) — 하반기 회복 기대 선반영 가능성. 화장품 내 APR만 유일하게 상향 — 업종 내 차별화 신호
투자/업무 시사점
  • 지금 포트폴리오 자가 점검 기준이 명확해진다: 보유 종목이 ① 주도주 섹터(원전·반도체·전력·통신)에 속하고 ② TP 상향 리스트에 들어가 있으면 홀딩 근거 충분. 반대로 소비재·인바운드·인터넷 플랫폼 비중이 크다면 실적 시즌에 컨센 하향 리스크 노출 — 손절 or 비중 축소 시점을 앞당길 필요 있음
  • 2차전지 TP 상향 군집은 단순 하반기 기대인지, 아니면 ESS·전력망 수요와 연결된 구조적 변화인지 추가 확인 필요 — 만약 후자라면 2차전지를 '전력 섹터'의 하위 카테고리로 재분류하고 비중 검토. 현대일렉트릭·대한전선·LG에너지솔루션의 공통 테마는 '전력 인프라 확대'임
