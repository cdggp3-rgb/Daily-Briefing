Claude Code 비용 80% 절감하는 settings.json 3줄과 14만명이 쓰는 everything-claude-code 설정법
핵심 개요

everything-claude-code GitHub 레포(14만 스타)를 소개하며, Claude Code의 컨텍스트 로트(Context Rot) 문제와 비용 절감 방법, 메모리 학습 시스템을 설명하는 영상.

주요 내용
  • 컨텍스트 로트 원인 4가지: 어텐션 희석, 명령 충돌, 토큰 예산 압박, 관련성 미스매치 — CLAUDE.md가 두꺼우면 그 자체로 성능 저하 원인
  • settings.json 3줄로 비용 80% 절감: ①모델을 Sonnet으로(60% 절감) ②maxThinkingTokens 10000으로(숨은 비용 70% 절감) ③서브에이전트 모델을 Haiku로(80% 절감)
  • /clear(무관한 작업 전환 시 컨텍스트 비움)와 /compact(마일스톤 사이 요약 압축) 구분 사용이 핵심. 구현 도중 compact 절대 금지
  • MCP 서버 10개 이하, 활성 도구 80개 이하 유지 권장 — 초과 시 20만 토큰이 7만까지 줄어듦
  • Continuous Learning v2: 작업 패턴을 Instinct 단위로 저장(신뢰도 0.3~0.9), 3개 이상 모이면 Skill 모듈로 자동 승격. /instinct export/import로 팀 공유 가능
투자/업무 시사점

직접적 투자 시사점은 없으나, AI 코딩 도구 생태계가 급성장 중이며 Anthropic의 Claude Code가 개발자 워크플로우의 핵심 인프라로 자리잡고 있음을 확인. Anthropic ARR 300억달러 급증과 맥락이 연결됨.

실행 아이디어

Claude Code 비용 최적화 settings.json 적용 검토. everything-claude-code 레포의 메모리/스킬 시스템 도입으로 일일 브리핑 워크플로우 효율화 가능.
