## 핵심 내용
노트북LM + 클로드 + 제미나이를 조합한 경쟁 제안서 PPT 자동 생성 워크플로우 소개. 우석진(채널 운영자)이 실무 제안서를 80점→90점 이상으로 끌어올리는 구체적 프로세스를 시연.
## 워크플로우 구조
1단계: 노트북LM에 RFP(제안요청서) + 회사 표준 제안서 업로드 → 환각 없는 본문 텍스트 생성 (비중 80%)
2단계: 제미나이 딥리서치로 최신 이슈/방법론 보완 (비중 20%) → 8:2 법칙 적용
3단계: 클로드에 템플릿 스킬 + 레이아웃 스킬 + 본문 텍스트 입력 → PPTX 자동 생성
4단계: 수작업 보완 — 개조식 단문 전환, 다이어그램/아이콘 배치, 컬러 통일

## 활용 포인트
기존 레포트 생성 파이프라인(report_generator)에 노트북LM 1단계를 추가하면 환각 리스크 감소 가능. 클로드 스킬 기반 템플릿 관리는 현재 미스터피피티 워크플로우와 병행 적용 검토할 만함.

  • 노트북LM의 폐쇄형 특성(업로드 소스 내에서만 생성)이 제안서에 최적 → 환각 제로, 팩트 기반
  • 클로드 스킬(템플릿+레이아웃) 2개를 미리 만들어두면 일관된 디자인 자동 적용
  • '정보 중심, 이미지 보조' 원칙 — 내용 완성 후 시각 요소 추가하는 순서가 핵심
  • 80→90점의 10점 차이는 사람이 메워야 함. AI가 잘하는 것과 사람이 해야 할 것의 구분이 워크플로우 설계의 핵심
